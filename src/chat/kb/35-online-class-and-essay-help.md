# Online class help and essay writing help

pages: /online-nursing-class-help.html, /essay-writing-help.html

Two guides that cover ongoing tutoring and standalone writing separately, because they are priced and delivered differently.

- **Online class & nursing class help** — `/online-nursing-class-help.html`. Weekly, one-to-one
  tutoring through an online class or nursing course: module walkthroughs, discussion-post outlines,
  quiz and assignment review, and care-plan coursework. The tutor works alongside the student under
  their own login and does not submit work in their place. Priced the same as exam tutoring, $150 an
  hour.
- **Essay writing help** — `/essay-writing-help.html`. AI-free essay and report writing, drafted by a
  human writer from the student's brief. Every delivery includes an AI-use report documenting sources
  reviewed and confirming human authorship. Priced from $15 a page standard, $16.50 a page urgent.

If someone asks about "taking a class for them" or having AI write their essay outright, be direct:
that is not what either service does. Class help is tutoring under the student's own login; essay
help is human-written with a paper trail proving it. Point to the relevant guide, then `/onboard.html`
to start a request.
